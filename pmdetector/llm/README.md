# PMDetector Taint Path Analysis

This module provides functionality for analyzing taint paths in smart contracts, grouping them based on similar characteristics, and generating human-readable narratives and evidence for each group.

## Overview

The taint path analysis process consists of the following steps:

1. **Parse taint paths**: Parse the taint path files generated by PMDetector's taint analysis.
2. **Group paths**: Group similar paths based on source function, sink function, and critical operations.
3. **Generate narratives**: Generate human-readable narratives for each path group using an LLM.
4. **Extract evidence**: Extract key evidence from the paths to support the narratives.
5. **Generate reports**: Generate JSON and text reports for the analysis results.

## Usage

### Command-line Interface

The `analyze_taint_paths.py` script provides a command-line interface for analyzing taint paths:

```bash
# Analyze all contracts
./pmdetector/llm/analyze_taint_paths.py

# Analyze a specific contract
./pmdetector/llm/analyze_taint_paths.py --contract 8c557c42_Compound_V2

# Specify input and output directories
./pmdetector/llm/analyze_taint_paths.py --input-dir path/to/taint/paths --output-dir path/to/output

# Use a specific LLM service
./pmdetector/llm/analyze_taint_paths.py --llm-service openai --llm-api-key your-api-key --llm-model gpt-4
```

### Python API

You can also use the Python API to analyze taint paths:

```python
from pmdetector.llm.path_analyzer import analyze_contract, analyze_all_contracts

# Analyze a specific contract
result = analyze_contract('path/to/taint/path/file.txt', 'path/to/output/dir')

# Analyze all contracts in a directory
results = analyze_all_contracts('path/to/taint/paths', 'path/to/output/dir')
```

## LLM Integration

The module integrates with LLM services to generate narratives for path groups. Currently, it supports:

- **OpenAI**: Uses the OpenAI API to generate narratives.
- **Anthropic**: Uses the Anthropic API to generate narratives.

You can configure the LLM service using environment variables:

```bash
export LLM_SERVICE=openai  # or anthropic
export LLM_API_KEY=your-api-key
export LLM_MODEL=gpt-4  # or claude-3-opus-20240229
```

Or you can pass the configuration as command-line arguments:

```bash
./pmdetector/llm/analyze_taint_paths.py --llm-service openai --llm-api-key your-api-key --llm-model gpt-4
```

## Output Format

The analysis results are saved in two formats:

### JSON Format

The JSON output contains the following structure:

```json
{
  "contract_name": "8c557c42_Compound_V2",
  "total_paths": 32,
  "total_groups": 5,
  "path_groups": [
    {
      "group_id": 1,
      "flow": "CToken.initialize -> CToken.liquidateBorrowFresh",
      "paths_represented": 3,
      "narrative": "User-provided data during contract initialization directly configures the `comptroller`, which is later called to determine the amount of collateral to seize during a liquidation.",
      "key_evidence": [
        {
          "step_number": 1,
          "code": "err = _setComptroller(comptroller_)",
          "file": "CToken.sol",
          "line": 1030
        },
        {
          "step_number": 2,
          "code": "comptroller = newComptroller",
          "file": "CToken.sol",
          "line": 2157
        },
        {
          "step_number": 3,
          "code": "(amountSeizeError,seizeTokens) = comptroller.liquidateCalculateSeizeTokens(...)",
          "file": "CToken.sol",
          "line": 1964
        }
      ]
    }
  ]
}
```

### Text Format

The text output is a human-readable report with the following format:

```
# Taint Analysis Report for 8c557c42_Compound_V2
Found 32 tainted paths grouped into 5 path groups.

## Path Group #1: Comptroller and Liquidation Logic Initialization
- Flow: CToken.initialize -> CToken.liquidateBorrowFresh
- Paths Represented: 3

- Narrative: User-provided data during contract initialization directly configures the `comptroller`, which is later called to determine the amount of collateral to seize during a liquidation.

- Key Steps with Code Evidence:
  1. `err = _setComptroller(comptroller_)` @ `CToken.sol:1030`
  2. `comptroller = newComptroller` @ `CToken.sol:2157`
  3. `(amountSeizeError,seizeTokens) = comptroller.liquidateCalculateSeizeTokens(...)` @ `CToken.sol:1964`

----------------------------------------
```

## Module Structure

- `path_grouping.py`: Functions for parsing and grouping taint paths.
- `narrative_generator.py`: Functions for generating narratives and extracting evidence.
- `llm_service.py`: Integration with LLM services.
- `path_analyzer.py`: Main functionality for analyzing taint paths.
- `analyze_taint_paths.py`: Command-line interface.
